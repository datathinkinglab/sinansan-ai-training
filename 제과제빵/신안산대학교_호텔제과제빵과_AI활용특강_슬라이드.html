AI가 판정표 대신 문장을 고쳐 씀같은 채팅에 “고쳐 쓰지 말고 표로만 판정해 줘”를 보냅니다.

문서가 아니라 글로만 답함같은 채팅에 “Canvas 문서로 다시 만들어 줘”를 보냅니다.
표가 깨지거나 칸이 틀림8장 수정 요청 문장으로 한 곳만 고칩니다. 작은 숫자는 Canvas에서 직접 고칩니다.
Docs로 내보내기가 안 됨콘텐츠 복사 → 8장 점검 칸 → 10장 ‘점검 칸 내용을 PDF로 인쇄’를 씁니다.
응답이 멈추거나 오지 않음같은 채팅에 “이어서 완성해 줘”를 보냅니다. 그래도 안 되면 8장의 대체 완성본으로 10장 인쇄를 합니다.

1. 스킬 지침그대로 쓰기

Gemini 맞춤설정 → 스킬 → 만들기 → 직접 만들기에 한 번 저장합니다. 이름: 제과제빵 보고서 작성

제과제빵 실습 기록을 바탕으로 호텔제과제빵과 학과 양식의 한국어 실습 보고서를 작성한다.
머리말(품목명·분류·제법·실습일·오븐 온도·굽는 시간) → 1 재료 배합표 → 2 제조 공정 → 3 관능 평가 → 4 고찰 순으로 정리한다.
재료 배합표에는 중량(g), 베이커스 %(밀가루=100), 트루 %(총 중량=100)를 소수 첫째 자리까지 계산해 넣는다.
수치와 단위를 보존하고, 오븐 설정값과 실측값을 구별한다. 없는 값은 기록 없음으로 표시한다.
관능 평가는 내부(조직·기공·속색·향·맛)와 외부(부피·껍질색·외형의 균형·굽기의 균일함·파쇄성)로 나누고, 기록에 있는 관찰만 해당 항목에 옮긴다.
관찰과 추정을 구별하고 확인되지 않은 원인을 단정하지 않는다. 고찰에는 '내 문장:' 한 줄을 비워 학생이 직접 쓰게 한다.
참고자료가 제공되면 학생이 확인한 주장과 범위만 인용한다. 요청한 형식에 맞춰 보고서 본문만 출력한다.
2. 초안 요청칸 채우기

스킬을 고른 새 채팅에 보냅니다. [ ] 안을 내 실습 기록으로 바꿉니다. 모르는 값은 ‘기록 없음’.

아래 기록으로 학과 양식 실습 보고서 초안을 써 줘.
문체 요청: [간결한 보고서체]
고찰 끝에 남길 질문: [이번 실습에서 확인하고 싶은 질문]

기록: [품목명]
분류: [제과 / 제빵] / 제법: [제법] / 실습일: [날짜]
재료: [재료와 중량 g, 쉼표로 구분]
공정: [단계 → 단계 → … · 온도·시간·분할 무게 포함]
관찰: [눈·입·손으로 확인한 것]
기록 없음: [재지 않았거나 기록하지 않은 것]
3. 초안 검토그대로 쓰기

초안을 받은 같은 대화창에 이어서 보냅니다.

위에서 쓴 초안을 원기록과 대조해서 검토해 줘. 문장을 고쳐 쓰지 말고 표로만 답해 줘.
표: 초안 문장 | 판정(기록으로 확인 / 추정·원인 단정 / 다음 계획 / 원기록과 다름) | 근거가 되는 원기록 | 빠진 기록
마지막에 고찰 끝 질문에 답하려면 어떤 기록이 더 필요한지 한 줄로 알려 줘.
4. 학과 양식 완성본칸 채우기

같은 대화창에서 입력창 아래 Canvas를 켠 뒤 보냅니다. [ ] 두 줄만 채웁니다.

위 초안과 검토 결과를 반영해서 학과 양식 실습 보고서 완성본을 만들어 줘.
A4 1쪽 분량으로, 표를 써 줘.

[양식]
머리말 표: 품목명 · 분류 · 제법 · 실습일 · 오븐 온도 · 굽는 시간
1. 재료 배합표 표: 재료 · 중량(g) · 베이커스 % · 트루 %
2. 제조 공정
3. 관능 평가 표: 내부(조직·기공·속색·향·맛) / 외부(부피·껍질색·외형의 균형·굽기의 균일함·파쇄성)
4. 고찰·개선 계획: 이번 실습의 한계 / 내 문장 / 다음 실습 계획
검증 메모 1줄: 대조한 항목 → 고친 내용

[반영할 내용]
고칠 문장: [검토에서 고르고 싶은 문장과 고칠 방향]
고찰의 내 문장: [내가 직접 쓴 한 문장]

[규칙]
- 없는 값은 '기록 없음'으로 써 줘.
- 확인하지 않은 원인은 단정하지 마.
- 참고문헌은 만들지 마.
5. 한 곳 고치기칸 채우기

Canvas 문서를 고칠 때 같은 대화창에 보냅니다. 한 번에 한 곳만.

지금 문서에서 [어느 부분]만 [어떻게] 바꿔 줘. 나머지는 그대로 둬.
6. 셰프 질문 (선택)그대로 쓰기

초안의 빠진 숫자·근거를 찾고 싶을 때 같은 대화창에 보냅니다.

위 초안을 셰프처럼 읽고, 재료 배합표·제조 공정·관능 평가에서 빠진 숫자나 근거를 질문 3개로만 물어봐. 문장을 대신 고쳐 쓰지는 마.
